# Multi-Provider LLM Architecture — Plan

## Decisions
- **Routing**: Hybrid (classification/local tasks → local, complex → API, local as fallback)
- **Providers**: Universal OpenAI-compatible client (Deepseek, Qwen, Groq, Together, etc.) + Anthropic
- **Streaming**: Not now (add later)
- **Config**: Env variables only

    """Backward compatible — inherits from OpenAICompatibleLLM."""

### Provider Registry

```python
PROVIDER_TYPES = {
    "openai-compatible": OpenAICompatibleLLM,
    "anthropic": AnthropicLLM,
    "llama-server": LlamaServerLLM,  # alias for openai-compatible
    "mock": MockLLM,
}

def create_provider(provider_config: dict) -> BaseLLM:
    """Factory: creates provider from config dict."""
    provider_type = provider_config["type"]
    cls = PROVIDER_TYPES[provider_type]
    return cls(**{k: v for k, v in provider_config.items() if k != "type"})
```

### Complexity Classifier

```python
def classify_complexity(prompt: str) -> float:
    """Returns 0.0 (simple) to 1.0 (complex)."""
    score = 0.0
    if len(prompt) > 200: score += 0.3
    if "```" in prompt: score += 0.3
    if any(w in prompt.lower() for w in ("объясни", "проанализируй", "напиши код", "сравни")): score += 0.3
    if any(w in prompt.lower() for w in ("посчитай", "что такое", "какой")): score -= 0.2
    return max(0.0, min(1.0, score))
```

### Routing Strategies

| Strategy | Classification | Tool Calls | Simple | Complex |
|---|---|---|---|---|
| hybrid (default) | local | local | local | best API |
| local-first | local | local | local | local → API fallback |
| api-first | best API | local | best API | best API → local fallback |

### Fallback Chain

```
Config: ROUTE_FALLBACK=local,deepseek,openai
Flow: try local → if fail → try deepseek → if fail → try openai → if fail → error
```

Each provider health-checked before use (cached for 60s).

## 3. `config.py` — Provider Config

### New Fields

```python
@dataclass
class ProviderConfig:
    name: str
    type: str  # "openai-compatible", "anthropic", "llama-server", "mock"
    enabled: bool
    base_url: str
    api_key: str
    model: str
    temperature: float = 0.7
    max_tokens: int = -1
    role: list[str] = field(default_factory=list)  # ["routine", "complex", "classification"]

@dataclass
class RouterConfig:
    strategy: str = "hybrid"  # hybrid, local-first, api-first
    fallback_chain: list[str] = field(default_factory=lambda: ["local"])
    classification_provider: str = "local"
    tool_call_provider: str = "local"
    complexity_threshold: float = 0.7
```

## 4. `gateway.py` — Factory

```python
def create_llm_from_config(config) -> BaseLLM:
    """Creates the right LLM based on config."""
    if len(config.providers) == 1:
        return create_provider(config.providers[0])
    return RouterLLM(
        providers={p.name: create_provider(p) for p in config.providers},
        config=config.router,
    )
```
